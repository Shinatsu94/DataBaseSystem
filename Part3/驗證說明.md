## 完整性與其他邏輯規則驗證

| 測試 | 結果 | 執行機制 |
|---|---|---|
| 重複主鍵或唯一電子郵件 | 拒絕寫入 | `PRIMARY KEY`、`UNIQUE` |
| 參照不存在的使用者、教室、節次或狀態 | 拒絕寫入 | `FOREIGN KEY` |
| 非法帳號格式、星期、學期、日期或節次範圍 | 拒絕寫入 | `CHECK` |
| 非教師帳號被指定為授課教師 | 拒絕寫入 | 課程 Trigger |
| 非管理員帳號被指定為審核人 | 拒絕寫入 | 審核 Trigger |
| 學生建立週期性借用 | 拒絕寫入 | 週期性借用 Trigger |
| 一般使用者冒用他人帳號申請 | 拒絕寫入 | 預約 Trigger |
| 停用教室接受待審核或已核准預約 | 拒絕寫入 | 預約 Trigger |
| 已核准預約與固定課表重疊 | 拒絕寫入 | 時段衝突 Trigger |
| 已核准預約彼此重疊 | 拒絕寫入 | 時段衝突 Trigger |

## View 與權限驗證

| 身分 | 驗證結果 |
|---|---|
| 學生 | 無基礎資料表查詢權；可查詢啟用教室、節次、狀態與個人資料；可維護自己的待審核預約及通知已讀狀態。 |
| 教師 | 繼承學生權限；可查詢課程與固定課表，並維護自己的待審核週期性借用。 |
| 管理員 | 可管理全部基礎資料、預約、審核、通知及 View。 |

一般使用者 View 以 `USER()` 取得 MariaDB 登入帳號，因此正式帳號名稱必須與 `users.user_id` 相同。

## 驗證查詢

```sql
SELECT TABLE_NAME, TABLE_ROWS
FROM information_schema.TABLES
WHERE TABLE_SCHEMA = 'classroom_rental'
  AND TABLE_TYPE = 'BASE TABLE';

SELECT COUNT(*) AS view_count
FROM information_schema.VIEWS
WHERE TABLE_SCHEMA = 'classroom_rental';

SELECT COUNT(*) AS trigger_count
FROM information_schema.TRIGGERS
WHERE TRIGGER_SCHEMA = 'classroom_rental';

SHOW CREATE VIEW classroom_rental.vw_bookings;
```
