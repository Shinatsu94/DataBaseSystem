## 專案目標

本系統用於管理學校教室之固定排課與臨時借用，確保同一間教室在相同日期與重疊節次內，不會同時分配給多筆已核准使用紀錄。

主要流程如下：

1. 管理員建立使用者、教室、節次與審核狀態基本資料。
2. 管理員匯入學期課程與固定授課時間。
3. 使用者提出單次或長期教室借用申請。
4. 管理員執行審核，系統保存審核歷程。
5. MariaDB 觸發器於核准前執行時段衝突檢查。
6. 系統保存通知，供使用者查詢借用結果。

## MariaDB Schema 摘要

| 設計項目 | 實作方式 |
|---|---|
| 儲存引擎 | 所有資料表使用 `ENGINE=InnoDB` |
| 字元集 | 所有資料表使用 `DEFAULT CHARSET=utf8mb4` |
| 實體完整性 | 每張資料表皆具有 `PRIMARY KEY` |
| 參照完整性 | 使用完整 `FOREIGN KEY (...) REFERENCES ... (...)` 定義 |
| 唯一性限制 | 使用 `UNIQUE` 保護電子郵件、節次名稱與狀態代碼 |
| 域完整性 | 使用 `NOT NULL`、`DEFAULT` 與 `CHECK` |
| 自動編號 | 交易資料表使用 MariaDB `AUTO_INCREMENT` |
| 時間欄位 | 節次起訖時間使用 MariaDB `TIME` |
| 衝突驗證 | 使用 `BEFORE INSERT`、`BEFORE UPDATE` Trigger 與 `SIGNAL SQLSTATE '45000'` |
| 星期轉換 | 使用 `WEEKDAY(date) + 1` 對應星期一至星期日之 `1` 至 `7` |

## 關聯閱讀方式

本系統現有資料關聯皆為 `1 : N`。局部圖使用實線表示必填外鍵，虛線表示子實體之外鍵允許為空值。

| 可選參照 | 意義 |
|---|---|
| `bookings.long_term_id` | 一般單次預約無須參照長期借用父單據。 |
| `bookings.course_time_id` | 非課程相關借用無須參照固定授課時間。 |
| `notifications.booking_id` | 一般系統通知無須參照單次預約。 |

## 執行方式

進入本目錄後，依序執行：

```powershell
mariadb -u root -p -e "CREATE DATABASE IF NOT EXISTS classroom_rental CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"
mariadb -u root -p classroom_rental < schema.sql
mariadb -u root -p classroom_rental < examples.sql
```
